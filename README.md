# 🖤 BELENTANI NOIACORE LAB — EAU NOIRE

**50 herramientas de código abierto para operaciones unipersonales en la nube**

---

## 🎯 Filosofía

Noiacore Lab es un laboratorio de herramientas para operadores unipersonales que trabajan en la nube. "Eau Noire" (agua negra) representa la profundidad, la automatización invisible, y el trabajo que fluye sin que lo veas.

Cada herramienta está diseñada para:
- Ejecutarse 24/7 sin intervención humana
- Operar en entornos cloud (VM, contenedores, serverless)
- Integrarse con APIs y servicios web autenticados
- Generar entregables verificables

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/belentani7/noiacore-lab.git
cd noiacore-lab

# Instalar dependencias globales
npm install

# Configurar variables de entorno
cp .env.example .env
# Editar .env con tus credenciales

# Verificar instalación
node scripts/verify-installation.js
```

---

## 📖 Uso

Cada herramienta tiene su propio README en `docs/tools/`:

```bash
# Ver ayuda de una herramienta
node scripts/uptime-monitor.js --help

# Ejecutar una herramienta
node scripts/uptime-monitor.js --daemon

# Ver todas las herramientas disponibles
node scripts/tool-registry.js list
```

---

## 🔐 Seguridad

- **Vault cifrado**: Todas las credenciales se almacenan en `vault/secrets.enc` (AES-256-GCM)
- **Sin commitear secrets**: `.gitignore` excluye vault/, logs/, backups/, .env
- **Rotación automática**: `secret-rotator` facilita la rotación periódica de API keys
- **Auditoría**: `audit-logger` registra todas las acciones sensibles
